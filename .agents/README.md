# Agent documentation routing

자동화 agent와 maintainer는 먼저 root [AGENTS.md](../AGENTS.md)를 따릅니다. 세부 계약은
[DEVELOPMENT.md](../DEVELOPMENT.md), [EVALUATION.md](../EVALUATION.md),
[RELEASE.md](../RELEASE.md)에 있습니다.

이 디렉터리는 실행 script나 credential을 저장하는 곳이 아닙니다. Task-specific 보고서는
root에 새로 누적하기보다 `docs/`의 해당 주제 문서를 갱신합니다.
