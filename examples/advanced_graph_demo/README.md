# 복합 그래프 실행 예제

이 예제는 외부 API, 모델, 데이터베이스, 정답표 없이 실행합니다. 문서 발췌와 단어 겹침 지표는
연결·실행·기록을 확인하는 용도입니다. LLM 성능이나 지식 그래프 품질을 측정한 실험이 아닙니다.

저장소 루트에서 설치한 가상환경을 사용합니다.

```bash
cd examples/advanced_graph_demo
../../.venv/bin/ragang run -F linear -Q custom/questions.txt
../../.venv/bin/ragang run -F hybrid_cycle -Q custom/questions.txt
../../.venv/bin/ragang run -F graph_module -Q custom/questions.txt
../../.venv/bin/ragang show -F hybrid_cycle
```

- `linear`: 입력 → 키워드 검색 → 문서 발췌. 질문마다 3단계입니다.
- `hybrid_cycle`: 입력 → 라우터 → 키워드·문서 그래프 검색 → AND 합류 → 초안 → 검증 정책 →
  라우터로 한 번 돌아가 재검색 → 합류 → 초안 → 검증 정책 → 최종 답변. 질문마다 14단계입니다.
- `graph_module`: 입력 → 실제 2-hop 문서 그래프 순회 → 문서 발췌. 질문마다 3단계입니다.

`hybrid_cycle`의 추가 검색은 흐름 검증을 위한 명시적인 한 번의 재시도입니다. 재시도가 답변의
정확성을 높였다고 주장하지 않습니다. 지표별 문서 수·단어 겹침을 개별적으로 확인하며 합산하지
않습니다. 대시보드에서 반복 실행 번호, 실제 다음 모듈, 부모 실행과 실패 상태를 확인할 수 있습니다.

문서 그래프의 간선은 예제에 사람이 지정한 입력입니다. 엔티티 추출·관계 사실성·커뮤니티 구성
품질은 평가하지 않습니다. 외부 GraphRAG도 검색 모듈로 감싸 입출력과 지연을 계측할 수 있지만,
내부 단계가 필요하면 별도 모듈로 노출해야 합니다.

AND 합류는 현재 활성인 모든 선행 모듈의 최신 출력을 조립합니다. 서로 독립적으로 도는 두
재시도 루프의 라운드를 자동으로 동기화하는 기능은 없습니다. 이 예제처럼 공통 라우터로
한 라운드를 시작하거나, 명시적인 라운드 식별자와 사용자 합류 정책을 사용해야 합니다.
