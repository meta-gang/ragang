RAGANG is a ground-truth-free evaluation and diagnosis framework for retrieval-augmented generation systems. It evaluates retrieval, generation, and end-to-end behavior without requiring a traditional gold answer dataset. RAGANG records evaluator health, distinguishes a valid zero score from a failed evaluation, preserves runtime configuration fingerprints, and helps users inspect evidence before considering possible failure causes. Baseline and candidate runs can be compared by score coverage, latency, and common evaluated metrics.
